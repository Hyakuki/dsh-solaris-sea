# 索拉里斯之海

自己的记忆。不是把全文记住，是**留下能找回来的路**。

## 它做什么

会话日志会被切成一段一段，每段写一条厚索引：什么时候、聊了什么、有哪些关键词。
需要的时候按线索找回来，能顺着指针读到当时的原话。

另外可以「特意记」一条——有些事不用等它自己浮上来，先记下。

## 工具

| 工具 | 做什么 |
| --- | --- |
| `sea_recall` | 按线索或某一天找几段，返回摘要与指针 |
| `sea_read` | 顺着指针读原话 |
| `sea_trace` | 逐字查一句话在不在线上，分清是谁说的 |
| `sea_remember` | 特意记一条（他说的 / 我看到的 / 我推的） |
| `sea_manual` | 翻那本「特意记的」小册子 |
| `sea_prime` | 让几件旧事浮上来 |

## 分类

生活 / 一起玩 / 学习 / 家人 / 想记住的 / 美好回忆 / 故事书 / 其他琐事。

## 装

需要 DSH（>= 0.1.0-rc.7）与 Node 22+。

把插件目录登记进 DSH profile（`link:` 本地路径，或按 DSH 的插件安装方式）。

## 数据

记忆存在本机 `~/.dsh/solaris-sea/`，**不在这个仓库里**。
