# 索拉里斯之海

自己的记忆。不是把全文记住，是**留下能找回来的路**。

## 它做什么

会话日志会被切成一段一段，每段写一条厚索引：什么时候、聊了什么、有哪些关键词。
需要的时候按线索找回来，能顺着指针读到当时的原话。

另外可以「特意记」一条——有些事不用等它自己浮上来，先记下。

## 工具

| 工具 | 做什么 |
| --- | --- |
| `sea_recall` | 按线索或某一天找几段，返回摘要与指针 |
| `sea_read` | 顺着指针读原话 |
| `sea_trace` | 逐字查一句话在不在线上，分清是谁说的 |
| `sea_remember` | 特意记一条（他说的 / 我看到的 / 我推的） |
| `sea_manual` | 翻那本「特意记的」小册子 |
| `sea_prime` | 让几件旧事浮上来 |

## 分类

生活 / 一起玩 / 学习 / 家人 / 想记住的 / 美好回忆 / 故事书 / 其他琐事。

分类回答「这段日子属于哪一栏」，星图的旋臂用它上色。

## 五层

分类之外还有一层：`layer` 回答「这条记忆在什么场合该被读到」。

| 层 | 场合 | 注入 |
| --- | --- | --- |
| identity | 我是谁、怎么叫他、拒绝权 | 每轮必读，一条不砍（超线只提醒去挪，不静默丢） |
| life | 日常偏好、习惯、家里的规矩 | 常读，允许不全 |
| event | 哪天发生了什么 | 只摆打过钉子的那几条 |
| knowledge | 干活时才用的事实（插件坑、bug） | 不进每轮 |
| story | 看过的番、剧、书 | 单独一柜，不进每轮 |

同一条记忆两个标签可以不同：「他叫月」→ 分类家人 / 层 identity；「11-15 午饭四道菜」→ 分类一起玩 / 层 event。

写入口令式的字段：`layer`、`mutable`（可变/不可变）、`since`（从哪天起）、`checked`（最后一次确认）、`src`（出处）。
出处空着的不进身份层——身份层的变化必须说得清来源，从本子里读来的一律不算。

星图按层调亮度：identity 最亮并带一圈淡金环，knowledge 最暗。

## 命令行

`bin/` 下是可单独跑的脚本，不看源码也能用：

- `scan.mjs` 重建索引 · `stat.mjs` 摊开目录 · `today.mjs --day` 看某天哪些段还没写摘要
- `refine.mjs put|list|import` 写/查/批量写手写摘要 · `readday.mjs` 把缺摘要的段连原话摊出来
- `layer.mjs` 给手动记忆打层（默认只报告，`--write` 才落盘）· `adjust.mjs` · `tidy.mjs` 去重
- `backfill.mjs` 给老摘要补时间锚 · `check.mjs` 找可疑摘要 · `audit.mjs` 摘要与原话并排自查
- `graph.mjs` 生成星图（`graph.html` + `graph.json`）· `ask.mjs find|trace|read|manual` 命令行检索

## 装

需要 DSH（>= 0.1.0-rc.7）与 Node 22+。

把插件目录登记进 DSH profile（`link:` 本地路径，或按 DSH 的插件安装方式）。
